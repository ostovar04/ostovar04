# Matin profile README — asset sources and editing notes

Theme-specific SVGs and GIFs live in `assets/light/` and `assets/dark/`; paired `<picture>` tags let GitHub select the matching theme. `README-preview.html` is self-contained and includes a light/dark preview toggle.

## Platform and skill marks

- **Python, Android, and Unity marks:** Simple Icons — [github.com/simple-icons/simple-icons](https://github.com/simple-icons/simple-icons).
- **Django mark:** Devicon — [github.com/devicons/devicon](https://github.com/devicons/devicon).
- **GitHub contact capsule:** authentic GitHub mark based on the official Octicons project — [github.com/primer/octicons](https://github.com/primer/octicons).
- **YouTube channel capsule:** authentic YouTube play mark sourced from the official Simple Icons YouTube SVG — [youtube.svg](https://raw.githubusercontent.com/simple-icons/simple-icons/develop/icons/youtube.svg).
- **Telegram channel and contact capsules:** authentic Telegram paper-plane mark from Simple Icons — [github.com/simple-icons/simple-icons](https://github.com/simple-icons/simple-icons).
- Brand marks are centered within their circular frames. Generic pictograms are used only for non-brand concepts such as backend, AI agents, web design, and marketing, which do not have a single official platform logo.
- Channel and contact capsules are original compact vector layouts, recolored for both themes. Educational-channel Telegram and Matin’s personal `@Beagk` contact are separate links.

## Original artwork

- The anime-inspired hero, animated bilingual star footer, collaborator-card backgrounds, and `stats-mascot.svg` banner are original artwork made for this profile; they do not use existing anime-franchise characters.
- The stats banner features an original chibi programmer illustration and `ostovar04`. Live stats and language cards in `README.md` fetch the account’s GitHub data from the stats service.
- `certificate-django.svg`, `certificate-ai-agents.svg`, `certificate-android.svg`, and `certificate-unity.svg` have their category names embedded in the artwork. They are editable placeholders, not evidence of credentials. Replace with verified title, issuer, date/year, and URL, or remove unused cards.
- Future-project entries are explicitly marked as editable planned concepts, not completed work.
- The footer GIF’s current bilingual copy is: «اگر این پروفایل براتون مفید بود، با یک ستاره حمایتش کنید» / “If this profile was helpful, please leave a star”.
